# 🚀 Skills de Documentación Técnica - Comienza Aquí

## ¿Qué Acabas de Crear?

Has creado un **conjunto de 4 skills profesionales** para generar documentación técnica personalizada para proyectos Python. Estas skills funcionan como "plantillas inteligentes" que generan documentación adaptada a tu proyecto específico.

---

## 📊 Resumen de las 4 Skills

| # | Skill | Cuándo Usarla | Genera |
|---|-------|---------------|--------|
| 1️⃣ | **tech-doc-readme** | Necesitas README o guía de instalación | README.md profesional |
| 2️⃣ | **tech-doc-api** | Necesitas documentar funciones/clases/arquitectura | API.md exhaustivo |
| 3️⃣ | **tech-doc-tutorials** | Necesitas ejemplos y tutoriales paso a paso | Tutoriales + notebooks |
| 4️⃣ | **tech-doc-specs** | Necesitas especificación formal y requisitos | SPECS.md completo |

```

### Para Proyectos Educativos
```
1️⃣ README: Propósito educativo, requisitos

## ❓ Preguntas Frecuentes

**P: ¿Puedo usar solo una skill?**
R: Sí, cada skill es independiente. Puedes usar solo tech-doc-readme si quieres solo un README.

**P: ¿Puedo modificar lo que generan?**
R: Completamente. Los documentos son punto de partida, adáptalos a tu necesidad.

**P: ¿Puedo usar para otros lenguajes (C++)?**
R: Sí, las skills mencionan Python pero se pueden adaptar a C++, JavaScript, etc.

**P: ¿Qué pasa si mi proyecto es diferente?**
R: Las skills son flexibles. Proporciona contexto específico y se adaptarán.

**P: ¿Cuándo actualizo la documentación?**
R: Usa las skills de nuevo cuando cambios significativos ocurran en tu proyecto.
