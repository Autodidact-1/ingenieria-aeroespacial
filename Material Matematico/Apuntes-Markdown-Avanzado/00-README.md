# Apuntes Markdown Avanzado

Esta carpeta es un curso corto en forma de apuntes: cada archivo `.md` explota
un grupo de funcionalidades de Markdown (y de LaTeX embebido) que van más allá
de títulos, **negrita**, *cursiva* y comandos LaTeX sueltos.

## Cómo usarla

1. Abre los archivos en VSCode con la extensión **Markdown Preview Enhanced**
   o **Markdown All in One**, o en **Obsidian**, para ver el renderizado real
   (tablas, matemáticas, diagramas Mermaid, etc.). El preview nativo de
   VSCode ya soporta la mayoría de esto, salvo Mermaid sin extensión.
2. Lee los archivos en este orden, de lo básico a lo avanzado:

| # | Archivo | Contenido |
|---|---------|-----------|
| 1 | [01-sintaxis-basica.md](01-sintaxis-basica.md) | Repaso rápido: títulos, énfasis, listas, citas |
| 2 | [02-tablas-y-listas-avanzadas.md](02-tablas-y-listas-avanzadas.md) | Tablas alineadas, listas de tareas, listas anidadas |
| 3 | [03-codigo-y-matematicas.md](03-codigo-y-matematicas.md) | Bloques de código con resaltado, LaTeX en línea y en bloque |
| 4 | [04-enlaces-imagenes-notas.md](04-enlaces-imagenes-notas.md) | Enlaces, imágenes, notas al pie, referencias |
| 5 | [05-diagramas-mermaid.md](05-diagramas-mermaid.md) | Diagramas de flujo, secuencia y Gantt con Mermaid |
| 6 | [06-html-embebido-y-extras.md](06-html-embebido-y-extras.md) | HTML dentro de Markdown, `<details>`, saltos de línea, comentarios |
| 7 | [07-plantilla-apunte-tecnico.md](07-plantilla-apunte-tecnico.md) | Plantilla lista para copiar y usar en tus apuntes reales |

## Nota sobre compatibilidad

No todo Markdown se ve igual en todas partes (GitHub, VSCode, Obsidian,
Pandoc/LaTeX). Cuando una función solo funciona en un entorno específico, se
indica explícitamente en el apunte correspondiente.
